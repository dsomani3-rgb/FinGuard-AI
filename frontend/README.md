# Frontend

This directory contains the frontend implementation of the **FinGuard AI** application.

## Technologies

- React
- Vite
- JavaScript
- HTML5
- CSS3

## Features

- Responsive user interface
- Financial preparedness dashboard
- AI-powered financial assistant
- Flood risk lookup
- Personalized recommendations
- REST API integration

## Getting Started

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```
