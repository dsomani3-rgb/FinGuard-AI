# 🛡️ FinGuard AI – Emergency Financial Preparedness Coach

> AI-powered financial wellness platform built for the **State Farm Financial Wellness Hackathon**.

## Overview

FinGuard AI helps users evaluate their financial preparedness during emergencies by analyzing their financial profile and providing personalized recommendations.

The application combines an interactive web interface with an AI-powered backend to deliver financial insights, risk analysis, and personalized guidance.

## Features

- 📊 Financial preparedness assessment
- 🤖 AI-powered financial coach
- 🌊 Flood risk lookup by ZIP code
- 💰 Personalized financial recommendations
- 🏠 Insurance product suggestions
- 📈 Financial risk dashboard
- ⚡ Fast API backend
- 🌐 Modern React frontend

## Getting Started

### Backend
```bash
cd backend

python -m venv venv

source venv/bin/activate

pip install -r requirements.txt

uvicorn main:app --reload
```

---

### Frontend
```bash
cd frontend

npm install

npm run dev
```
