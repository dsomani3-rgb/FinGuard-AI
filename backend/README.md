# Backend

This directory contains the backend implementation for the FinGuard AI application.

## Technologies

- Python
- FastAPI
- Uvicorn

## Responsibilities

- Financial data processing
- AI recommendation logic
- REST API endpoints
- Request validation
- Business logic

## Running the Backend

Install dependencies:

```bash
pip install -r requirements.txt
```

Start the server:

```bash
uvicorn main:app --reload
```

The API will run at:

```
http://localhost:8000
```
